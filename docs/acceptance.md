## 实测数据

字体预热后，每组采样 25 次。从字段操作到更新帧，个人基准 P95 为 17.3 ms，公开示例为 17.4 ms；调整全局字号到更新帧分别为 20.7 ms 和 32.5 ms。PRD 阈值分别为 200 ms 与 500 ms。不同设备的操作延迟可能不同。

通用导入另行验收了真实 DOCX、文字层 PDF 和纯图片 PDF。通过系统选择器测试替身指定本地文件，实际运行 Swift 解析与 Vision OCR，再在应用内合并、拆分、改归属、创建。导出测试同样只替代路径选择，文件生成与写入走生产代码。OCR 输出可在创建前逐项校正。

## 复现

在 macOS 上运行 npm ci、npm test、npm run package、npm run test:release。使用 RESUME_TEST_SEED 指向个人起稿可以额外运行 tests/paper-acceptance.cjs。所有自动化测试使用临时数据库。公开仓库仅提供合成测试材料。

发布 ZIP 的 SHA-256 为 `1326a987356626e2de490e63cd18389bb3258ff4a448abe988dffcf648853b4a`。本机安装验证使用同一应用载荷，应用包通过 codesign --verify --deep --strict，压缩包通过完整性检查。该版本使用 ad-hoc 签名。
