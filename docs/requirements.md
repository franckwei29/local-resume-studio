# 离线简历编辑器 · 产品规格

本文记录 v1.0 的单模板规格。下一版增加 30 款新布局，原有蓝灰双栏列为 00，共 31 款供选择。具体交互和新增验收条件见[多模板库与样式切换需求](template-library-requirements.md)，可用浏览器打开[交互样张](template-gallery.html)逐款对照。

目标平台为 Apple Silicon Mac。应用独立运行，使用结构化表单编辑一份或多份岗位简历。公开版首发起稿为虚构的产品设计师示例，个人安装可加载单独的本机起稿。PDF 与预览共用同一份分页数据。

| 页面 | 交互及结果 |
|---|---|
| 简历库与回收站 | 支持缩略图、列表、按名／时间排序、按文档名／目标岗位搜索、新建、独立复制、重命名、详情、导出、可编辑备份、软删除、恢复和永久删除。 |
| 编辑工作台 | 左侧提供两栏的模块和折叠表单，右侧显示连续 A4 页面。填写、裁剪、显示、隐藏、删除、设定分页符均反映到预览，点击纸上内容可定位回表单。文档名称与纸上标题分别保存。 |
| 内容 | 个人信息行、岗位、教育、任职、项目、评价、技能、语言、自定义模块与签名。正文支持多级子项目、标签、局部强调、链接、圆点及数字列表，开始／结束年月和至今分别记录。 |
| 排序 | 模块可在两栏间移动，条目在所属模块中移动，正文块与要点在自己的同级列表内移动。一次拖动对应一次撤销。 |
| 排版 | 单一蓝灰双栏模板。侧栏边界约占纸宽 34%，圆形头像直径约占纸宽 21%。左右栏独立续排，初始为两页。修改后按内容增删页面，最后一页侧栏有弧线收尾。字号、行高、间距、边距、配色可调。屏幕缩放独立于纸张尺寸。 |
| 导出 | 下载纵向 A4 PDF，正文可选择、搜索、复制，链接有目标，照片和矢量装饰保留。文件对话框处理取消和替换。写入失败保留已有文件与当前草稿。 |
| 本地导入 | 读取 DOCX 段落、PDF 文字层，图片型 PDF 调用 Mac Vision 文字识别。核对页允许修改、跳过、拆分、合并及重新归类。确认后新建文档。 |

## 验收基准

完整基准含 2 段教育、3 段工作、2 个项目、4 段评价及 7 条技能。排版目标为默认两页，续页承接同一栏的后续内容。预览和 PDF 在相同比例下的关键位置误差最多 1 mm。已加载字体后，普通字段输入上屏至预览更新目标为 P95 200 ms，全局字号变更至完成分页目标为 P95 500 ms。

A01–A16 依次覆盖首次起稿、版式、复制隔离、字段与富文本、拖动与撤销、跨栏与隐藏、分页、样式与缩放、窄栏与长文本、草稿校验、管理与恢复、PDF 一致性、失败恢复、全流程离线、抬头及头像、栏目语言。真实个人数据的验收在独立本机目录执行。
